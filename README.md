# Blackwood Furnitures – Premium Custom Furniture Website

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

A premium, fully responsive website for **Blackwood Furnitures**, a custom furniture manufacturer based in Nairobi, Kenya. The site showcases their collections, portfolio, and enables clients to request quotes via a modern, AJAX-powered form.

---

## 🚀 Features

- **Premium Design** – Elegant typography, dark/light contrast, gold accents, and smooth animations.
- **Fully Responsive** – Mobile-first layout with hamburger menu and optimized touch interactions.
- **Formspree Integration** – Quote form submits directly to your Formspree endpoint with client‑side validation and success feedback (no backend required).
- **Performance Optimized** – Lazy-loaded images, deferred JavaScript, and CSS animations with `prefers-reduced-motion` support.
- **SEO & Structured Data** – JSON‑LD for local business, Open Graph tags, and descriptive meta tags.
- **Accessible** – ARIA labels, keyboard navigation, focus states, and semantic HTML.
- **Analytics Ready** – Google Analytics 4 placeholder (easily enable with your measurement ID).

---

## 📦 Technologies

- **HTML5** – Semantic markup with Schema.org structured data.
- **CSS3** – Custom properties, CSS Grid, Flexbox, and responsive breakpoints.
- **JavaScript (Vanilla)** – Intersection Observer, scroll effects, AJAX form submission, and mobile menu.
- **Formspree** – Serverless form handling.
- **Google Fonts** – Playfair Display & Inter.
